Fruit Shelter Lab

Multi-fruit shelter builder with same-folder PNG/MP3 defaults, custom images/music, acid rain, and arcade physics.

Mode

Editor: click to place. Drag selected pieces. Q/E rotates. Delete removes selected. Fruits are no longer limited to one.

Tool

Selected / New Object

Storm / Physics

Custom Assets

Default assets load from the same folder as this HTML: fruit_orange.png, fruit_apple.png, fruit_lemon.png, fruit_grape.png, crate.png, plank.png, metal.png, bumper.png, acid_drop.png, background.png, music.mp3, and optional SFX MP3s.
